## Formats and assumptions

- `buildingOptions/*.stl`: alternative building geometry.
- `energy/alt_1.csv`: building identifier and energy totals for Option 1, joined to a DTCC CityModel by UUID.
- `noise/*.csv`: noise samples read as coordinate/value rows by the original loader.
- `radiation/*.csv`: spatial samples with `x`, `y`, and `value` columns; baseline and alternative difference interpretations are unchanged.
- `wind/Option_*/*.csv`: surface cells/nodes used to reconstruct the colored wind mesh.
- `wind/surfaceLawson_option_0.png`: original wind legend.

`wind/removecols.py` is retained as the original preprocessing recipe; its companion notebook is empty in the source. The code's fixed origin, elevations, and transformations are documented in [the reproduction guide](../docs/reproduce.md). Exact coordinate-system and input-generation metadata must be confirmed by project members before reusing the data elsewhere.

## Restore larger files

```sh
python3 scripts/fetch_archived_data.py
python3 scripts/fetch_archived_data.py --check
```

Large inputs remain available through the original immutable Git commit until a dedicated archive is supplied. This is not a Zenodo deposit. A compatible CityModel JSON was not included in that commit; the application allows it to be uploaded or skipped.
